Features · 功能
🔊

内置发音

逐词播放（F2 快捷键）、连播、自动播放；自动优先英音，Chrome 无本地语音时自动切换在线词典发音。

🎲

乱序测试

每个章节一键打乱单词顺序听写，防止背顺序，成绩计入历史并标注「乱序」。

⚙️

发音设置

语速、每词重复次数、连播间隔、词典发音模式，设置自动保存到浏览器。

👁️

逐词查看答案

练习过程中可随时揭示或隐藏当前行的正确拼写，不必等到整章完成。

💡

全量双语例句

5873 个词条全部内置英文例句与中文翻译；1700+ 个唯一词条匹配经过筛选的自然中英句对，并支持完整句子朗读。

📒

错词本

自动收录所有历史错词，按章节分组，支持单章节或全部错词重练。

📈

历史统计

记录每次听写的日期与正确率，折线图展示进步趋势，可回看错词详情。

💾

本地存储

数据保存在浏览器 localStorage，无需账号、无需联网，支持导入导出迁移。

How to Use · 使用方法
01

选择章节

从首页点进任意章节，例如 3.2、11.4。

02

开始听写

点「开始听写」或「乱序测试」，配合发音边听边打，Enter 跳下一格。

03

批改复习

完成后自动判分，错词进错词本，随时回看历史趋势并针对性重练。

现在就开始练习 ✨
